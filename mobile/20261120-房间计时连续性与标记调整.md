# iOS 房间计时连续性与标记调整

版本：1.6.3-ios-alpha.8。范围：iOS 本地包；本轮未更改官网或线上服务。

- 三场景空座按钮可见圆面约 28px（原为 44px），头像也缩至 28px，点击范围保持 44px。去掉透明点击范围上的毛玻璃，缩小短线与标签。
- 移除房间的 Solo room、页面底部 Internal alpha 文案及标题中的 Internal Alpha。
- 声音条件从“必须在窗景”调整为“同一专注在房间或窗景运行中”。进入未开始专注的房间仍无声音；暂停、结束、休息及进入后台仍按原有语义停声。
- 房间沿用当前 sessionStartedAt、elapsedSeconds、remainingSeconds 和同一个音乐元素，不重建播放器、不重置进度。确保 ticker 运行并保存当前会话。
- 房间显示倒计时和六个图标控件；返回窗景只切换视图。设置和声音面板根据可用空间在控件上方或下方弹出。

验证：21/21 Node 检查通过（含资源与源码基线、离线边界、音频条件、自动换景）。Chrome 844×390 实际操作三个场景：房间内计时递减、音乐 currentTime 增加且 paused=false；咖啡厅暂停保持 24:09，恢复并切回窗景后保持同一时刻继续，音乐从约 52 秒继续；设置可打开，结束进入总结。森林声音面板位于屏内且可滚动。

资源已通过 Capacitor 同步到 ios/App/App/public，mobile-experience.js、mobile.css、mobile-config.js 和 index.html 与 dist 字节一致。Xcode 已完成编译并进入 Installing App，随后提示 Unlock 梁逍逍的iPhone to Continue / device is locked，尚未确认新版本在设备上启动，等待手机解锁。未直接读取 iPhone 屏幕或验证真机音频听感。
