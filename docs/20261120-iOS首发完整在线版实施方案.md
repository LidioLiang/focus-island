## 商业行为

- 沿用原商业文档的一次 25 分钟试用作为当前实现；开始即消费，正常重试不重复消费。
- 商品候选 ID：`online.focusisle.plus.monthly`、`online.focusisle.plus.annual`，同一订阅组。价格只能来自 StoreKit；未配置时不显示示例价格。
- 已有有效网页会员/终身权益优先识别，避免重复购买。
- 未订阅也能查看历史、删除账号、恢复购买和管理订阅。
- Apple `sync_pending` 或待批准状态会禁止再次付款；重新进入仍保留提示。原生购买前先重试未完成的已付款交易。
- Sandbox 交易不会写入生产会员权益。TestFlight 沙盒完整解锁仍需隔离测试环境或受控测试权益策略，不能视为已具备正式收费闭环。

## 账号与隐私边界

- App 的登录令牌保存在 Keychain，不提供 JS 获取令牌的方法。无效 Bearer 不回退到网页 Cookie。
- 头像以原始 multipart 字节通过固定原生 HTTPS 路由上传，服务端验证格式/体积并重新编码。
- 验证码使用独立、不保留 Cookie 的 WebView，只接受本站主文档返回的验证码结果；Supabase 完成服务端验证。
- 注册确认页清除 URL fragment 后提示回 App 登录。恢复页仅将邮件 fragment 发送到同源端点，验证新鲜 recovery AMR 后签发一次性 HttpOnly 重置授权，沿用已有网页重置流程。
- Supabase 需要允许 `https://focusisle.online/mobile/confirmed` 和 `https://focusisle.online/mobile/recover` 回跳；邮件/验证码实际配置尚未联调。
- 删除账号需先结束专注，二次确认后删除本账号上传头像与 Auth 用户；本地仅清理该账号的数据。Apple 订阅需要在 Apple 设置中另行取消。
- 通知权限不云同步。当前原生包关闭 PostHog；网页保留原有可选统计。

## 开关和构建

- `MOBILE_AUTH_ENABLED=false`：邮箱原生入口默认关闭，独立于 Apple 收费开关。
- `APPLE_IAP_ENABLED=false`：购买接口默认关闭。
- Apple 服务端环境变量：`APPLE_IAP_ENVIRONMENT`、`APPLE_APP_ID`、`APPLE_ROOT_CERTIFICATES_BASE64`、`APPLE_IAP_PRIVATE_KEY`、`APPLE_IAP_KEY_ID`、`APPLE_IAP_ISSUER_ID`；私钥只允许在服务端。
- `FOCUS_IOS_CHANNEL=online-beta npm run ios:prepare`：构建内部在线候选包并同步 Xcode。
- 不传 channel 时仍构建可回退的 `offline-alpha`。两种包均保留 `releaseReady: false`。
- 当前资源约 227 MiB；这是未压缩资源包体积，不是最终 IPA 大小。

## 恢复发版工作的顺序

1. Mac 解锁后检查账号页、会员页和横屏小尺寸，完整 Xcode Build 并安装测试。
2. 部署新 API；配置 SMTP、验证码域名和邮件回跳；在受控测试环境开启原生账号入口。完成注册→确认→登录→上传头像→云记录/设置→退出→删除验证。
3. 补齐 Apple 登录与 OAuth 回跳实现及凭据；配置商品、订阅组、服务器通知和密钥，完成 Sandbox/TestFlight 的完整权益路径。
4. 双设备选座/云同步，25/50 分钟专注、房间返回、锁屏、来电、耳机断开、断网恢复验收。
5. 核实隐私表单、素材许可、客服与审核账户，生成 Archive 和截图。全链路通过后再打开正式收费，上传审核；审核通过后发布。
