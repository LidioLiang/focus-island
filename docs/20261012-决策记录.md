# 决策记录

创建日期：2026-10-12  
用途：记录项目重要方向变化，避免后续对话重复争论或走回头路。

## 2026-10-12：确立 `prototype/` 为唯一主线

背景：
项目根目录曾经同时存在多个代码包和多个站点导出包，容易导致重复开发和改错版本。

决定：
只把 `prototype/` 作为继续开发、测试和上线验证的唯一主线。

结果：
历史实验代码和导出包只作参考，不再作为并行开发入口。

## 2026-10-12：创建 GitHub 私有仓库作为回滚记录

背景：
项目需要可回滚、可追踪的版本记录。

决定：
创建 GitHub 私有仓库 `LidioLiang/focus-island`，并把 `prototype/main` 推送到 GitHub。

结果：
`github/main` 是当前主线远端；`origin` 保留为托管平台远端，二者不要混用。

## 2026-10-12：从成熟工程路线切换到极速 MVP

背景：
P1 被拆成工程底座、质量上线、前端拆分等多个模块后，项目开始变复杂，用户难以判断当前重点。

决定：
暂停多场景扩展、大规模前端拆分、复杂测试体系、登录、付费和完整后台。

当前只做：
咖啡厅 25 分钟专注主流程，以及结束后的极简反馈入口。

结果：
短期内工程结构可以不完美，但必须更快上线给 5 到 20 个真实用户测试。

## 2026-10-12：PRD 改为轻量执行口径

背景：
完整 PRD 对产品长期规划有帮助，但当前阶段会拖慢 MVP 上线。

决定：
以 `docs/20261012-MVP极速上线PRD.md` 作为当前唯一执行口径。

结果：
旧 PRD 和旧任务清单只作背景参考，不再决定当前开发优先级。
