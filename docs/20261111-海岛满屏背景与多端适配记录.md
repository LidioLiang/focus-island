# 2026-11-11 海岛满屏背景与多端适配（v1.5.2）

阶段：静态 MVP 首页视觉与响应式适配。用户要求海岛为视觉中心，四周天空和海面随屏幕裁切，移除毛玻璃补边。

## 改动

- 原实现将 1586×992 主图按屏幕宽度完整展示，其余高度以 blur(26px) + backdrop-filter 填充。现在海岛首页不渲染该模糊背景层。
- 新增同一海岛的方形、竖向天空/海面扩展背景。桌面与超宽横屏采用方形，手机和竖屏平板采用纵向扩展图；通过 picture 按方向选择当前资源，避免初次双图下载。
- 图片与六个地图钉共用同一画布；画布居中按视口尺寸计算，始终覆盖屏幕，溢出仅裁切。横屏画布边长 max(100vw,100dvh,min(145vw,205dvh))；竖屏保持 2:3 比例，宽度 max(100vw,100dvh×2/3)。
- 根据两张母图分别标定咖啡厅、图书馆、森林、湖滨、海滨、雪山入口。竖屏保留至少 44px 点击宽度；其他房间与沉浸背景不改。
- 无 API、数据库或计时规则变更；保留 v1.5.1 所有点击延迟修复。图像来源、原始尺寸和生成要求已登记到素材权属记录。

## 交互边界

- beforeInteractive 的展示脚本先于 app.js 运行，因此背景常量使用独立 `/assets/` 路径；已验证在 app 全局变量尚未建立时脚本可初始化。
- 海岛与 world 使用 overflow:clip，超大背景不成为可被聚焦操作滚动的容器。
- 首页唯一设置弹层由 CSS 固定右上位置，覆盖历史动态 left/top，换时长、图像解码与转屏时保持屏内。
- 顶部导航透明空隙不接收指针，只有真实标题/工具接收，防止短横屏雪山地图钉被遮住。
- Chrome 已视觉检查 1920×1080 横屏和 390×844 竖屏，无模糊补边，六区对应；原窗口尺寸已恢复。截图在本地 prototype/docs/evidence/20261111-island-{desktop,mobile}.png。
