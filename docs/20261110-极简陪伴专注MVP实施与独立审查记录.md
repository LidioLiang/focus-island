## 独立审查与修复复核

用户明确要求“做完之后再用一个独立的审查 agent”。功能实现与本地检查完成后启用独立只读审查，审查者依据重新定位方案及用户后续视觉修订，独立检查真实源码并运行测试。

| 问题 | 风险 | 修复与证据 |
|---|---|---|
| 暂停 PATCH 在途时结束状态被队列删除 | P1，再次触发旧专注卡住 | 队列 revision、仅删发出版本、持续 drain、终态优先；审查者独立 VM 复现从只发 paused 改为 paused→ended_early，新增回归通过 |
| 完成页左上 Island 返回后复用旧云会话 ID | P1，第二轮未新建记录 | 返回时 reset、新占座清 cloudFocusClientId；新增完整浏览器路径用例 |
| 请求失败保留旧真人“正在专注” | P1，虚假实时陪伴 | presenceUnavailable 标记、过期/未确认头像隐藏、断网提示和禁用未确认选座；另加 2 秒本地过期重绘，无额外网络轮询 |
| 触屏轻点无法唤醒顶栏 | P2 | pointerdown 唤醒，保留键盘唤醒 |
| 活动专注中切换身份遗留旧座位 | P2 | 活动会话禁止打开/提交账号切换，正常身份变化轮换座位 session ID |
| 离线后再次在线仍绕过 API | P2 | 分房成功统一清除 offlineFocus |
| 重复开始按钮与旧一次性试用文案 | 方案偏差 | 仅保留上浮菜单单一 Start，可选注册改为账号管理表达 |

独立复核结论：此前 3 项 P1 均已修复，未发现修复引入新的 P1；92/92 Node 测试通过，代码层核心调整符合重新定位方案。复核指出的两个较小问题（静置头像过期重绘、旧注册试用文案）也已随后收口。
