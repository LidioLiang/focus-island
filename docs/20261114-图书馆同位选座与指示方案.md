# 图书馆同位选座与指示方案

阶段：静态 MVP 房间层交互统一，发布版本 v1.6.2。

## 实现

- 图书馆六席的空位按钮与已选头像共用现有 `avatar_anchor`，按钮不再使用位置更低的独立 `hit_area`。
- 空位按钮与头像统一为 44px 圆形区域；点击成功后头像在原位置替换按钮。
- 复用咖啡厅指示线：宽 1px、白色 38% 不透明度、桌面长 14px、窄屏长 9px，无末端圆点且不接收鼠标事件。
- 保留现有占座、1.9 秒 Settling in、0.6 秒沉浸画面渐入和头像专注波纹动画。
- 开发者移动头像或按钮时同步两个坐标；图书馆使用新的 `library:unified` 本地布局键，旧的独立坐标保留但不再套用。
- 咖啡厅与森林行为保持不变；数据库、账号和在线占座协议无修改。

## 发布边界

本轮不修改数据库、账号、登录、计时状态或在线占座协议。发布必须先通过远程 Chromium 与数据库 CI，再合并到正式分支并核对正式域名。
