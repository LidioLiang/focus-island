# 森林区实施与独立审查记录

日期：2026-11-11（Asia/Shanghai）。阶段：静态 MVP 森林场景扩展，目标版本 1.5.0。

## 实施范围

- 基于用户批准的六座预览，制作无人物、无 UI 的三桌六席正式母图。实际头像与按钮由共享界面绘制，不使用示例人物作为在线成员。
- 海岛开放 Forest，复用咖啡厅/图书馆匿名身份、自动分房、原子预留/占座、15 秒心跳、45 秒租约、Realtime、Solo 降级及单用户单活跃专注。
- Rootside Desk / Deep Forest Desk / Glowing Ferns 对应三组座位默认景色，另有 Sunlit Canopy / Misty Woodland；共五张图，个人选择独立保存；换景、房间往返不重置计时和租约。
- 25/50/Open、暂停/继续/重开/结束、历史与恢复复用共享流程；森林独立环境音、音量、布局和开发者入口，诊断包括九间后台房间。
- 桌面与 compact（画布宽度 <700px）森林布局分开保存；窄屏错排六个点击区，保留44px最小触控目标，开发者看到和普通模式一致的坐标。既有咖啡厅与图书馆 key 兼容。
- 新增配置、通用场景能力判断及增量迁移，未引入 Godot、旧家具编辑器、动物互动或伪造在线人数。

## 独立审查

用户明确要求完成后由独立 agent 审查。本轮独立 reviewer 对照代码和方案发现并推动修复：

1. P1：旧 occupySelectedSeat 限定 café/library，forest 绕过实际占座。改为共享场景能力判断；新增三场景真实函数行为测试，验证 reserve → occupy → focus 顺序。
2. P2：森林环境声与咖啡厅合成底噪叠加。改为按 ambientAsset 选择声源；新增通道隔离测试。
3. P2：手机固定 CSS 坐标覆盖开发者校准；第一次修正后又发现桌面保存会导致手机按钮重叠。改用一致的坐标函数及单独 compact 布局 key，添加桌面保存→手机编辑→关闭→刷新测试。
4. 修正图片切换测试立即读取未加载图片的误报；用等待实际图片解码的断言。

实施中另修复图书馆音频尚未解码时切入森林会阻塞新音频的问题：异步加载按 URL 分离，迟到结果不能跨场景播放。
