# Academy Library 实施与功能验收

2026-11-10。目标版本 1.4.0。定位：极简陪伴与专注；完整 2D 母图、真实在线头像、第一人称近景；无 3D、换装、奖励与伪造伙伴。所有新用户界面采用英语。

## 实施范围

| 项目 | 实现 |
|---|---|
| 入口 | 海岛书本地图钉 Academy Library，悬停 Open now，其他未制作区域仍 Coming soon |
| 房间 | 一张含完整桌椅的六座母图，2 Window Desk / 2 Reading Table / 2 Quiet Alcove |

## 结构与数据

`lib/scene-catalog.json` 同时驱动前端与服务器合法场景/房间列表。新增 `scene-runtime.js` 封装场景配置、偏好与专属环境音；复用既有 API，保留旧咖啡馆布局 key。

迁移 `20261110143530_academy_library_shared_scenes.sql`：新增图书馆房间；allocate/resume限定目标场景；reserve/resume保护更新的用户会话；start校验场景/房间和在线座位所有权，保持全局单活跃专注与幂等。所有RPC保留 auth.uid、固定 search_path、authenticated 执行权限与直接表禁写。

房间快照/订阅启动、重连均检查场景与生命周期；结束会使旧请求失效，并排空在途恢复后释放租约，防止总结页被旧回包重新占座。座位丢失时计时仍需按正常流程结束。Realtime订阅变更使用代次防止旧订阅覆盖新场景。

## 验证与审查

本地执行 lint/typecheck/Node测试/Next生产构建。测试库执行可回滚生命周期断言；仓库 pgTAP 新增20项图书馆检查，CI重建数据库后运行。Playwright增加图书馆完整流程、25/50/Open、移动与横屏、Solo、按场景独立布局与导出；保留咖啡厅及账户回归。

本机浏览器启动被 macOS MachPort 权限限制，不能将本机浏览器测试声称为通过；实际浏览器结果以 CI 为准。音频自动化能校验加载、暂停/静音和迟到解码，不能代替耳机音质验收；25/50分钟真实长时运行不由短时CI替代。

用户要求的独立审查已发现并推动修复：启动脚本遗漏、图书馆旧渲染分支、海岛布局入口、结束后的迟到恢复/快照、丢失座位后的结束确认、迟到presence启动、首次声音偏好隔离。所有结论以最终复审及 CI 为准；本记录后续补充发布事实。
