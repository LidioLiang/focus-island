# 当前执行上下文

创建日期：2026-10-12  
用途：让新的对话或新的开发者在 3 分钟内理解当前项目重点，避免重新扩大范围。

## 当前目标

极速上线 MVP。

当前只验证一件事：安静的虚拟陪伴和咖啡厅氛围，能不能让用户更愿意开始并完成一次 25 分钟专注。

## 当前只做

- 咖啡厅专注主流程。
- 25 分钟专注计时。
- 选座、开始、暂停、继续、结束。
- 结束后的极简反馈入口。
- 上线前的最小检查。

## 当前不做

- 不做新场景。
- 不做注册登录。
- 不做付费。
- 不做复杂排行榜、成就、历史统计。
- 不做完整后台。
- 不做大规模前端拆分。
- 不继续扩大测试体系。
- 不做移动端深度适配，只保证不崩。

## 当前主流程

```text
打开链接 -> 进入咖啡厅 -> 选座 -> 开始 25 分钟 -> 暂停/继续/结束 -> 反馈
```

## 当前判断标准

每次开发前只问一个问题：

```text
这件事能不能帮助真实用户更快完成一次 25 分钟专注？
```

如果不能，先不做。
