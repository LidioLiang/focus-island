# 极简 UI 对齐、地图钉与全屏适配修订

按用户本轮截图反馈，候选版本 v1.2.1：

1. 修复旧 `.seat` 双列 grid 影响加号位置，圆形按钮使用单格并居中 SVG。
2. 倒计时三操作移到数字下方，保留鼠标/键盘/触屏入口，并保留操作区域间的悬停连接。
3. 返回按钮仅留箭头，使用居中的对称箭头图形，保留无障碍名称。
4. 专注顶栏顺序为 Scene → Sound → Settings → Your avatar，最右为头像；不更改入口原功能。
5. Focus length 的 25 min、50 min、Open 固定同一排，标题独立一行，窄屏不换行。
6. 六区地图钉改成用户第七图的整体水滴轮廓，雾蓝外形、蓝色内环、浅色圆心和区域图标；无常驻文字。
7. 海岛/咖啡厅使用铺满可用视口的同场景模糊毛玻璃背景；主图按原始比例完整显示，避免裁掉座位或坐标错位；宽屏、竖屏边缘不留纯色空白。
8. 开发者面板默认移到左上，可拖动标题移动、键盘微调、收起/展开；保留座位坐标调整与保存，解决六号座位被遮挡。

本轮不修改数据库、账号、声音实现或计时权限。沿用现有美术素材，没有新外部图像或依赖。

## 竖屏旧限制修复

实际手机尺寸复核发现历史样式在竖屏给整个 `#app` 添加 blur/brightness 并禁用 pointer-events。新版不再要求旋转设备，已为极简 UI 明确恢复清晰显示与点击。320×820 实际 Chrome 已验证设置弹窗、关闭按钮和计时三选项可正常使用，毛玻璃仅作用于场景填充层；截图 `20261110-v1.2.1-mobile-controls.png`。浏览器窗口尺寸已恢复。

开发者六号位拖动/面板移动与收起用例在首轮 CI 已通过。首轮新增窄屏用例失败揭示上述历史限制，修复后正在重跑；同时将拖动后的误触抑制限制在标记本身，避免影响面板工具。
