# 2026-11-11 海岛画质修复（v1.5.3）

用户故事：打开海岛首页 → 浏览器按屏幕比例加载对应画面 → 海岛满屏且建筑树木清晰度改善 → 六区入口保持可点击。

## 根因与修复

旧方形图 1254×1254 在 1920×1080 视口放大为 2214×2214；海岛主体只占原图中间一部分，扩图后主体细节像素不足。首页没有残留 blur 滤镜。

- 普通横屏换为 1672×941 的细节图，采用最小覆盖画布，1920×1080 时约 1920×1080.6，线性放大从 1.77 降至 1.15，单位屏幕长度可用源像素提高约 54%。主体在源图中占比也提高，取消无必要的方形额外变焦。
- 屏幕比例达到 2:1 时使用独立宽景构图 1586×992，纵向焦点 40%，同时保留山顶和主要岸线；3440×1440 时画布宽 3440，比旧图同宽下的源像素密度提高约 26%。
- 竖屏保留原 1024×1536 构图；picture 在加载时只选择匹配的一张图，不额外下载其他画幅。
- 两张新图按实际像素编码 WebP quality 94，分别约 785KiB/694KiB，不插值放大。它们不是原生 4K，工具本轮输出未达到所请求 4K/32:9；本次改善来自主体细节、源像素利用和正确显示比例，不宣称 4K/Retina 一比一像素覆盖。
- 六区地图钉按三套图的实际地标分别标定，和图片共享画布。保留 overflow:clip、透明导航点击穿透、设置弹层屏内定位、v1.5.1 点击修复。
- 首页 CSS/JS 缓存版本分别更新为 v5/v8；版本 1.5.3。无数据库或专注会话逻辑变化。
