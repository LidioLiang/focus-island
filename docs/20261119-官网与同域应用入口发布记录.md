## 地址与运行方式

- 官网：https://focusisle.online/
- 软件：https://focusisle.online/app
- 客服：https://focusisle.online/contact ，mailto:support@nisoniy.com
- 12 个官网页面，价格、场景、博客和文章均独立地址。
- Next.js Proxy 将官网白名单路径映射到同部署的静态 HTML；/app 页面直接复用原有软件组件。没有跨域代理，没有新增远程上游依赖。
- 同源 cookies、localStorage 和 API 路径保持不变。旧首页账号、恢复、支付与邀请参数以 307 转至 /app 并完整保留查询参数。
- 官网不初始化匿名账号，不发分析事件。原软件的分析同意流程保留。
- 默认正式官网允许抓取，提供 12 页 sitemap；软件入口不索引，静态副本通过 canonical 指向正式地址。
- canonical 和页面地址采用 Next.js 默认的无结尾斜杠形式，首页保留 /。

## 维护

源码位于 marketing/，npm run build 的 prebuild 自动生成 public/_website 和 public/website-assets。页面路由白名单位于 lib/marketing-routes.ts。新增页面需要同步更新白名单。
