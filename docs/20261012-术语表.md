## 极速 MVP

只完成咖啡厅 25 分钟专注主流程，用来快速给 5 到 20 个真实用户测试。

## 主线代码

`prototype/`。后续开发、测试、上线验证默认只改这个目录。

## 当前 PRD

`docs/20261012-MVP极速上线PRD.md`。这是当前唯一执行口径。

## 旧 PRD

根目录的 `20261011-MVP产品需求文档.md`。它保留为产品背景参考，不再作为当前优先级依据。

## 主流程

```text
打开链接 -> 进入咖啡厅 -> 选座 -> 开始 25 分钟 -> 暂停/继续/结束 -> 反馈
```

## 咖啡厅

当前唯一必须跑通的场景。图书馆、森林和海岛扩展都不是上线前必须完成的内容。

## 反馈入口

用户结束专注后留下感受的入口。优先使用外部表单、简单链接或邮件，不为了它新建后台。

## 留档
